# Simulador do Modelo OSI - Terminal Acessível

Projeto web desenvolvido para simular o encapsulamento e desencapsulamento de dados através das 7 camadas do Modelo OSI, operando como um terminal de linha de comando.

### Foco em Acessibilidade
A interface foi construída para ser 100% navegável por teclado e otimizada para leitores de tela (NVDA, JAWS, VoiceOver). O uso do atributo `aria-live="polite"` permite que a injeção de logs via DOM seja narrada em tempo real, sem truncar o áudio do usuário.

### Tecnologias Utilizadas
- HTML5 Semântico
- CSS3
- JavaScript Vanilla
